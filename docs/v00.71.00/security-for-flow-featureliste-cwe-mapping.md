# Vollständige Featureliste mit CWE-Mapping für `security-for-flow`

Grundlage: `Featureliste v8: Passwort- und Credential-Sicherheit für security-for-flow`.

Hinweis: Die Spalte „Mitigierte CWE(s)“ ist als fachliche Zuordnung zu verstehen. Ein einzelnes Feature beseitigt eine CWE meist nicht isoliert; die Schwachstelle wird durch das Feature verhindert, reduziert oder im Zusammenspiel mit anderen Features beherrschbar gemacht.
